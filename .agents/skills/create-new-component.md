# Instructions for Creating a New Component
To create a new component in the codebase, follow these steps:
1. If not provided, ask whether it is a library component or an application component.
2. If not provided, ask which app or lib it should be created in.
3. Ask for the name of the component to be created.
4. Use the appropriate Nx generator command to create the component.

# General instructions
* Always ask for any missing information needed to create the component.
* Always use the appropriate Nx generator command to create the component.
* If the generator errors out at any point, relay the error message and start over from step 1.
